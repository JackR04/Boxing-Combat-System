# Boxing-Combat-System

Prototype combat system made in C#

FighterBase = Fighter Mechanics

EnemyBase = Enemy Decision Making and Mechanics

AnimationEvents = controlling scripts with animations

CameraSensitivity = Handling sensitivity for both mouse and keyboard and controller

CombatEffects = Handles playing audio and particle effects

GameManager = Handles the gameplay, when levels start and end, respawning player and enemies etc.

HUD = Handles players HUD including the stat allocation screen and in game health and stamina bars

Healthbar = Enemies healthbar and animations as well as floating damage numbers

HitStop = Stops time on attack for a short time to increase feel of impact

PlayerMovement = Handles inputs

SpawnNextEnemies = Spawning next levels enemies on player trigger

Vignette = handles fade in and out of multiple vignettes, e.g stun, hit and low health vignettes

animatorController = triggers animations to respond to player inputs and enemy decisions
